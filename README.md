## 🕷️ Spidy Developer Portfolio

A modern, responsive, and animated portfolio website built using **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. This website showcases services, skills, projects, and contact information for **Spidy Developer**, a freelance Full Stack Web Developer.



## 🌐 Live Demo

🔗 https://spidy-developer.elansakthiswari.workers.dev



## ✨ Features

- 🎨 Premium Modern UI/UX
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Vite
- 🎬 Smooth Animations using Framer Motion
- 🌙 Dark Theme (Black & Red)
- 💼 Services Section
- 👨‍💻 About Section
- 🛠️ Skills Showcase
- 🚀 Portfolio Projects
- 📩 Contact Form with WhatsApp Integration
- 📱 Social Media Links
- 📌 Sticky Navigation Bar
- 🔥 Hover Effects & Glow Animations

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Sakthiswari-E/Spidy-Developer.git
```

Navigate to the project

```bash
cd client
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
